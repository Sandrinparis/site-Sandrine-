Questions fréquentes

Quelques réponses aux questions les plus courantes.

Comment effectuer une demande ?

Vous pouvez utiliser la rubrique Réservation ou Contact et transmettre les informations demandées dans le formulaire.

Une demande est-elle automatiquement confirmée ?

Non. L'envoi du formulaire constitue une demande. Une confirmation explicite est nécessaire avant qu'une réservation soit considérée comme définitive.

Comment vérifier une disponibilité ?

Consultez la rubrique Disponibilité puis indiquez la date souhaitée dans votre demande.

Comment modifier ou annuler une demande ?

Utilisez la rubrique Contact afin de demander une modification ou une annulation et consultez les conditions applicables avant toute confirmation.

Quelles informations dois-je transmettre ?

Transmettez uniquement les informations nécessaires à votre demande. Ne communiquez jamais de mot de passe, code confidentiel ou code de sécurité.
